Run it on a VPS

From a fresh login to a runcastle that keeps burning after you log out, reached from your own browser over an SSH tunnel.

Getting started Preparation Project session The pipeline Gates Compare

In order

  1. Log in as a normal user with sudo. The install refuses to run as root, and tells you how to make that user if you only have root.
  2. Run the install. It shows the list and asks once. 
    $ curl -fsSL https://runcastle.dev/install.sh | bash
    Unattended, answer for it: 
    $ curl -fsSL https://runcastle.dev/install.sh | bash -s -- --yes --agent claude
  3. Log out and back in, so the docker group applies.
  4. Sign in to Claude Code: claude auth login.
  5. Save the burn token: runcastle token. It has you run claude setup-token and checks what you paste.
  6. Keep it running: runcastle service install. It starts at boot, after Docker, and restarts if it stops.
  7. Reach it from your own machine, then open http://localhost:4512: 
    $ ssh -L 4512:localhost:4512 user@host

The server has no login. It listens on 127.0.0.1 only, so the tunnel is the way in. Never expose it publicly.

Firewall and SSH hardening are yours to do.
