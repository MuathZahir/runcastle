Another machine or your phone

Run runcastle on a server, so features keep building while your laptop is off, and check on them from your phone.

Get started How a feature goes The orchestrator Another machine or your phone

On a server

  1. Log in as a normal user that can use sudo. The installer will not run as root.
  2. Run the installer. --yes answers its question for you, and --agent picks the coding agent to install: claude, codex or both.
    $curl -fsSL https://runcastle.dev/install.sh | bash -s -- --yes --agent claude
  3. Log out and back in. The installer added you to the docker group, and that only takes effect on a new login.
  4. Sign in to your coding agent.

    Claude Code: sign in, then save the token workers use while you are away.

    $claude auth login
    $runcastle token

    Codex: sign in. Workers use the same login.

    $codex login
  5. Make runcastle start when the server boots, and restart if it stops:
    $runcastle service install

Reach it

runcastle has no login of its own, so it only listens on the server itself. Never open it to the internet. From your own computer, connect with SSH and forward its two ports:

$ssh -L 4512:localhost:4512 -L 4514:localhost:4514 user@host

Then open http://localhost:4512 in your browser. Port 4514 carries the design previews. Without it, the Design view stays empty.

Move an existing setup

Already using runcastle on your laptop? This copies your projects, with every branch and any uncommitted work, and runcastle's own data, to a Linux or macOS machine:

$runcastle move user@host

Run it with --dry-run first to see what it would copy, without copying anything.

On your phone

Install Tailscale on the machine running runcastle and on your phone, signed in to the same account. In runcastle, open Settings → General → On your phone, turn the link on, and scan the QR code. On a new Tailscale network, Tailscale first asks you to turn on HTTPS, once; runcastle links you to that page. The link only works inside your own Tailscale network, never on the public internet.

Add the page to your phone's home screen and turn on notifications: runcastle then tells your phone when a feature needs you. On an iPhone, notifications only work from the home-screen app.
