Get started

runcastle is the software development engine. Other tools hand you a coding agent and leave the process to you. runcastle runs the process itself: plan, design, build, review, test and merge, with Claude Code or Codex doing the work.

Install

The installer lists what your machine is missing, asks once, and installs it.

$curl -fsSL https://runcastle.dev/install.sh | bash
>irm https://runcastle.dev/install.ps1 | iex

Then start runcastle, and open http://localhost:4512 in your browser:

$runcastle

It runs on your own machine. There is no account to create, and nothing passes through a server of ours.

What you need

  • Claude Code or Codex, installed and signed in. They run on your own Claude or ChatGPT plan.
  • Git.
  • Docker or Podman, running. Workers build your code inside containers, so you need one before the first build.
  • macOS 13 or later, Windows 10 (version 1809) or later, or Linux. The installer also installs Bun, which runcastle runs on.

Setting up Docker or Podman on each system, and fixes for common problems, are in the README.

First run

The first time you open runcastle, a short setup asks for your git name and email, since runcastle commits for you, and connects Claude Code, Codex or both.

Claude Code or Codex

Each step can run on its own model, from either agent: the chats, building, and reviewing. In the example below, Codex builds and Claude reviews.

Your first feature

Open a git repo as a project. runcastle first works out how to install, run and test your app, by running each command for real. Then start a chat and describe what you want built.

Designing screens needs an app with a web interface. Test drives work for web apps and for HTTP APIs. Every runcastle term is explained in the app: the ? at the bottom of the sidebar opens the Glossary.
