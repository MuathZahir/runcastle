Get started

runcastle is the software development engine. It runs the whole process for you, from plan and design to build, review, test drive and merge, on Claude Code or Codex, where other tools hand you an agent and leave the process to you.

Get started How a feature goes The orchestrator Another machine or your phone

Install

$ curl -fsSL https://runcastle.dev/install.sh | bash   # macOS and Linux
> irm https://runcastle.dev/install.ps1 | iex          # Windows
$ runcastle                                            # then open http://localhost:4512

It shows what is missing and asks once. Everything runs on your machine: no account, no hosted backend.

What you need

  • Claude Code or Codex, signed in, on your own Claude or ChatGPT plan. Nothing goes through runcastle.
  • Git, and Docker or Podman before the first round of workers.
  • macOS 13+, Windows 10 1809+ or Linux. The installer brings Bun.

Setup per platform and troubleshooting are in the README.

First run

A short wizard sets your git identity and connects Claude Code, Codex or both.

Claude Code or Codex

Pick a model for each step and mix them: plan with Claude, build with Codex.

Your first feature

Open your repo as a project. runcastle first works out how it installs, runs and test drives, by running it. Then start a chat and say what you want built.

Designing screens live needs a web frontend; test drives cover web apps and HTTP APIs. New words like round are explained in the app: the ? in the sidebar opens the Glossary.
