runcastle in ninety seconds

A ninety-second walkthrough of runcastle. A feature is named and sized; a real agent session opens with the brief already injected and grills the idea into a spec that is committed to the repo; the spec is split into ten dependency-ordered tickets; one Burn click hands them to six sandboxed Docker agents that pick up every unblocked ticket at once and commit to a single branch; four features run side by side; the finished branch is test-driven on its own port and merged.
