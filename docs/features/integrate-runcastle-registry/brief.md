# Integrate runcastle registry

I would imagine the default workflow being the one we have now (maybe we also add a review step). But users can create other workflows, for things like "Idea Validation", "UX Optimization", etc.. I would imagine people being able to invoke the workflows somehow. Maybe the main action would be invoke workflow instead of "New Feature". The idea is still fuzzy and needs to be explored
