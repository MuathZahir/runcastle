Under the hood

Seams

  • README content test (existing), rewritten to the new contract.
  • Update check, with the new usageSignal setting ('on' | 'off' | unset) and install-ID presence injected.
  • Phone-link service with the Tailscale CLI faked: a status gains httpsNeeded, the address Tailscale printed; turn-on stops on "Serve is not enabled".
  • PhoneLinkBody, GlossaryDialog, Term, HelpMenu: component tests; lib/glossary.ts holds the one list.
  • A vocabulary guard test: retired words in user-visible web strings fail, with an allowlist.
  • Standing notices on a phone: "on your computer", no desktop-only buttons.

Order

This project runs one worker at a time, so the six build tickets run in sequence. True edges: the Glossary waits for the web words (its hints sit on rewritten strings), the README waits for everything it describes.
