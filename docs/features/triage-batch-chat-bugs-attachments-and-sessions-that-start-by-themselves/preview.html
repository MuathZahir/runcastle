Under the hood

Where each fix lands, by layer.

packages/core

The thread fold (foldThread): a thread-wide record of subagents shown, and a split at a steered message keeps the turn's calls and subagents.

apps/web

A small attachment store on IndexedDB with a memory copy, used by the chat hook (useThread). The feature chat starts itself when its conditions hold, and drafts move to the thread as it gets its id.

packages/server

The launch (launchSession) runs one at a time per feature, so two tabs cannot create two chats.

packages/skills

The project and feature skills. These reach live sessions only after a release and reinstall.
