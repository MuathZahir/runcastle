The show

Two changes to the landing page. Pictures are from a browser at 1440px; "after" is the live page with the text edited in place.

1 · The hero becomes the hook 2

"The software development engine." replaces the headline; the paragraph under it goes. Install chip and scene stay.

  • Three lines on desktop, one on tablet, three on a phone; the install chip stays above the fold on a 1366×768 laptop.
  • Title, descriptions, social tags and structured data take the new pitch; the social card (og.png) is recaptured from the new hero.

2 · The Windows button works

The logic was fine. The closing castle's floor grid is drawn 176px past its box and, from 768px wide up, sits on top of both buttons, so the click never reaches them.

  • Picking Windows also switches the hero's chip, since both read one choice. Default stays macOS and Linux; no guessing, no remembering. 3

3 · The design canvas gets the same edits 1

The page is generated from a Claude Design canvas this run could not reach. The lead edits the generated files; you make three matching edits on the canvas so the next port keeps them.

  1. Headline text → The software development engine.
  2. Delete the hero's subtitle paragraph.
  3. Add pointer-events:none to the castle scene's style rule (.cs).
