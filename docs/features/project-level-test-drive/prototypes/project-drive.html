        1

        A Test drive card on the project page

        It sits between New chat and Notes, as a secondary button, because New chat stays the page's one solid button. The card says what a drive will do before you click: which branch your checkout is on, and which setup, dev and stop commands will run. Anything not set shows as "nothing set", with a link to Settings.

        if another drive already holds the slot, the button is disabled and names that drive, like the feature page does.
        2

        The drive takes over the page body, like a live chat

        The header names the branch and repo path, so you can see when your checkout isn't on main. The stage is the feature drive's own: the app in a frame, Select area, Reload, Open app ↗, the dev-server strip and its output. Stop drive ends it. Project page steps back to the resting page while the drive keeps running, and a pill in the titlebar shows it is still live.

        3

        The right rail is the project inbox, live

        Every note from the drive is an ordinary project note. That covers the drag-select capture, the rail's box, and Ctrl J. Notes from this drive are listed first. Notes that were already open sit below them, so you can see if something is already reported. Each drive note carries a small "drive · main" tag.

        what exactly a note records about its drive (decision 5).
        4

        Stop, and the notes are waiting on the Notes card

        The resting page's Notes card shows the drive notes with their tag and screenshots. Triage picks them up the same way it picks up any note. Nothing else happens when the drive ends. There's no summary and no prompt, because the inbox is the exit.

        +

        A chat and a drive at the same time

        Tick "a project chat is also open" above, then start a drive. A Chat | Drive switch appears in the drive header. Both keep running, and the switch only changes which one fills the body.
