Three smaller commands

runcastle tokenHidden paste of the Claude token. Refuses a cut-off value and replaces the old line.
runcastle service installKeeps runcastle running on a Linux server, with nobody logged in. 7

Under the hood
install.sh / install.ps1Root check, Bun, unzip, runcastle, then hand over. Nothing else.
Doctor probesThe existing checks, reused, plus Bun's minimum version.
Install planA pure function: probe results and machine facts in, a list out.
Setup runnerRuns the plan, re-checks, reports what is left.

Install commands stay in the doctor's advice, so setup and the doctor cannot disagree. Git uses the system package manager; a Mac without Homebrew gets Apple's own dialog as an afterwards step. The scripts are tested in clean Linux containers and in the platform smoke workflow on macOS, Linux and Windows.
