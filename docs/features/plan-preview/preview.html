What is left out

Later laps, if a test drive asks for them

  • A warning when the preview is older than the decisions
  • The preview on the live Building, Review and Shipped pages
  • Redrawing the preview during a lap planned from review

Not this feature

  • Marking which decisions the agent made for you
  • Commenting on the preview, element by element
  • Rendering the real app or its real components
  • Publishing the preview outside this machine
  • Previews for quick changes

Under the hood

Skill pack

  • Ideate: draw the preview when decisions lock, check it against decisions.md, wait for the human
  • A starter file beside the ideate skill: runcastle's tokens and the fixed parts
  • Ideate and revisit: redraw when a decision changes at planning
  • Tickets: point a screen ticket at one screen block

Server

  • The docs watcher wakes the page for preview.html, not only .md
  • The feature read says whether a preview exists and when it was written
  • The existing doc read returns the file as text
  • No new route, table, pipeline state or gate

Web app

  • One preview panel, used by the planning body and the read-only Planning view
  • A sandboxed frame fed the text, with the content policy and the app's light or dark mode added
  • A full-window dialog around the same frame
  • A "Preview ready" chat notice, a new kind beside "Spec written"
