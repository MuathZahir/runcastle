Under the hood

Handback mark

A new field on the feature: when it was handed back and the summary. Written by hand_back; cleared by the orchestrator's acting tools, a human message, release of the hold, leaving active. Each change emits an event.

Feature need

The old holdable-kinds list goes. Held = mark outstanding, holder present, under an hour, and the need is the handback's own or a machine state whose start is at or before the mark. A held need never outranks an unheld one.

Running work

The background-work log event carries subagents as a list (id, title, start). Claude: from the runtime's live list. Codex: the host's set from start/end reports. Old count-only events still read. Thread activity: commands capped at 10 min, subagents not.

Fold

The chat's work item gains what still runs in it, matched by id or title, else the newest fold before its start. Ending a turn leaves a still-listed subagent running. The fold component shows a spinner and the line.
