Under the hood
  • MCP: a lead's hand_back({ summary }); the feature handback card is a new prompt display beside the worker one.
  • Orchestrator notifier: its table cut to three waking events; the keyed holds and the held-news label removed.
  • Boot: the reconcile hands its cut-off chats to a carry-on wake once the server listens.
  • Thread host: the usage-limit line with a settings link; the reset wake only with the new setting on, for every stopped turn.
  • Compaction: lead-chats-stay-small's triggers widened to project threads; the 1 MB cap no longer starts fresh orchestrator chats.
  • Skills: the lead's hand-back rule; the project skill's news paragraph and its re-read after compaction.
  • Workers are not available in this session's runcastle (no start_worker), so the lead builds it with its own sub-agents, then one review round.
