Under the hood

Error patterns move from the burner into a pure classifier; the worker service retries on its turn-ended hook and watches turns for stalls. Boot reconcile wakes cut-off workers. Worker sandboxes call the image build, seed from the per-project cache, run the setup command, take the CPU cap and the guard hook; the conversation file is copied out before removal and tokens recorded. The review is a worker kind: a host thread in the checkout for drive reviews, a sandbox for gates; findings are re-keyed to it. Tickets, rounds and runs become frozen history read by a History view and get_work_record, whose seam lookup also matches the files workers changed. Then sandcastle, the burner, review gates, the per-tool timer and every ticket and round writer are deleted; leads with unfinished tickets get one note. ADR-0020 records the move.
