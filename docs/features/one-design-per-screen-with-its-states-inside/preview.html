How it gets built

No new screen in the app, so nothing was designed for this plan. The change is text: I make it myself, then one review round checks it.

  • The design guide: one page per screen, the switcher's shape, Tweaks inside, the switcher kept on commit
  • The planning-alone guide: check every state of every design
  • The plan and ticket guides: a designed screen lists its states
  • The show-design tool's description: a screen example, plus one sentence stating the rule 6
  • Review round: one review ticket reads the diff against the spec
