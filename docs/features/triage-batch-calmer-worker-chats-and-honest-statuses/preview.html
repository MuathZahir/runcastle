What is left out

Later

  • Catching a lead's plain-words question while its workers run (the challenge to decision 13), if you want it

Not this feature

  • How workers hand back: no new summary field
  • Merging text stretches or hiding the agent's words
  • The one-drive-slot rule: no queue, no take-over
  • The Review Package's layout
  • A drive slot on the phone
  • The retired draft "open a worker while it works"

Under the hood
  • Work summary: a pure function over a stretch's steps, in the web, reusing the call-group words ("Read 3 files"); one work-row component serves every chat.
  • Workers card: the workers service appends a worker-started event (id, label, purpose, kind) to the lead's thread on start_worker and start_review; the core thread fold gathers one turn's events into one card, outside any work row; rows read live status from the feature's worker list, as feature cards read live features.
  • Status fix: a new "workers at work" fact in the feature need; the quiet "lead replied" branch does not stand while it is true. Sidebar, header and alerts all read that need.
  • Drive: the server's drive state already records purpose (human or review); it gains the worker id when the Review worker takes the slot; the drive info and the web's drive state carry both; the feature view's "is driving" becomes "the human is driving".
  • Seams: the thread fold, the summary function, the feature need, the workers service, the drive info, the drive slot and notices, the handback and assignment cards.
