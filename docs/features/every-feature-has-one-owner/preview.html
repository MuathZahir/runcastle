Under the hood
On the feature·the existing holder (null = yours), plus two new fields: its chat and finish: you | show | merge
Owner changes·one service: owner control mutation, first typed message in the lead's chat, take_feature, create_feature, a plan-agreed hand_back, a replacement chat. Each emits an event and clears the handback.
Tool rules·wait_for_you refused under a chat; hand_back reaches the owner, else its chat; orchestrator acting tools refuse human-owned features except send_to_feature; show_plan/show_design take a slug from a chat.
Status·the pure feature-need function learns the owner chat's name and whether it is asking; "With the orchestrator" becomes "With <Chat>".
Today's features·a one-time boot step: held stay held with "shows you before merging"; unheld are yours.
