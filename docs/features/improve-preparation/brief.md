# Improve Preparation

Currently the preparation is hidden in the settings panel. No one would see it there. Also, when a project is created, there's a small section at the bottom calling the user to do the preparation. But most people will miss it (their focus would be on the new feature button). I believe the whole page (when there's no features yet and when the user hasn't completed the preparation should be a CTA to do the preparation). If the user already has features but didn't do the preparation, it should appear on the left sidebar at the bottom so the user remembers to do it. I want to remove the "AFK" preparation. I want the preparation to always be interactive. Since the AFK version can make the user lose patience since he doesn't see what's happening. Remove it and just keep the interactive version.
