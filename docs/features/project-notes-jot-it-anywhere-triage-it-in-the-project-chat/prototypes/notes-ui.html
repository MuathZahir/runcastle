      The Note control matches the titlebar

      An icon button, the same size and weight as theme and panel next to it. The tooltip names it and shows Ctrl J. No text label, so nothing sticks out.

      a bordered text button that looked like it came from another app.
      2

      Capture works like the command palette

      Centered near the top, like Ctrl K, with a light scrim so you can still see what you're noting. The cursor starts in the input. One large line, with no Save button, because Enter saves. Where the note goes is shown as "to runcastle-demo", and a pasted picture shows up as a chip.

      off-center box, click needed before typing, disabled-looking Save.

      Saved confirms in place, then gets out of the way

      The bar becomes one line: "Noted in runcastle-demo · 5 open · View". The scrim lifts right away and the bar closes itself after about 1.5 seconds.

      a wide, empty box with the whole app still dimmed behind it.
      3

      The inbox is a list, not a form

      One dense row per note: picture, text, and a quiet time. Edit, dismiss and delete are icons that appear on hover or keyboard focus, and delete only turns red under the pointer. The count and Triage sit in the header, and the paragraph is gone. Triaged notes fold into one quiet line.

      three bordered buttons on every row, a red-outlined Delete ×N, a paragraph, and a floating Triage button.
