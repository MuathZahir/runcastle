Under the hood

Built by the lead in this checkout, no tickets. Then one review round: a real browser at phone width walks every Back path and takes screenshots.

The history layer (one place writes history)

Each entry the app pushes remembers the path it came from. Moving to that path calls history.back() instead of pushing.

/f/xpush →/f/x/design {from:/f/x}close → back()/f/x

The dialog shell (every overlay and sheet)

On the phone: open pushes one entry at the same address; a pop closes the dialog; closing by button steps off the entry; an action after closing waits for that step; an orphan entry after a reload is skipped.

The composer

The thread column stops leaving the meter out on the phone. The model chip truncates first at 360px. The phone mockup page gains the meter.

How it is checked

Unit tests on the history layer and the dialog shell (open, Back, close, reload, two in a row); typecheck; the review round on a real history stack.
