# Disclosure

A collapsed section with a chevron — the home for long secondary content (drive instructions, full digests, raw logs).

**Consumer provides** `title`, optional `icon`, optional `aside` (a count or timestamp), `open`, and the body as children.

**Do** collapse anything the user reads once: "How to drive this app", "Full account — digest". **Don't** render such blocks open by default inside a bordered box.
