# Icon

The runcastle icon set: 16×16, 1.5px round stroke, `currentColor` — copied from `apps/web/src/icons.tsx`.

**Consumer provides** `name` and optional `size` (14 in small controls and meta lines, 16 beside `ui` text, 20 in empty states). Colour comes from `icon`; hover and selected rows switch it to `text`.

**Do** pair every nav item, menu item, tab and primary/secondary button with an icon. Icons carry meaning *with* a word, never instead of one except in labelled icon buttons.
**Don't** use emoji or unicode glyphs (⎇ ⚙ ✓) as icons.
