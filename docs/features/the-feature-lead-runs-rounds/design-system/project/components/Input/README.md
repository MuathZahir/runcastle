# Input

A single-line text field on `surface-inset` with a `border` hairline; focus turns the border `accent` and adds the focus ring.

**Consumer provides** `placeholder`, `label` (when no visible label), optional leading `icon`, optional `kbd` hint, `size` (`md` 28 · `lg` 32), optional `width`.

The search field is `Input icon="search" kbd="Ctrl K"` — in the sidebar top, not the title bar's far right.
