# SectionLabel

A group heading in the sidebar or a list: 12px medium, sentence case, `text-tertiary`, with an optional count and one trailing action.

**Consumer provides** the label as children, optional `count`, optional `action` (an `IconButton size="sm"`).

**Replaces** the uppercase letter-spaced labels ("FEATURES", "SHIPPED 104", "CONVERSATIONS"). Groups are distinguished by their label, never by a coloured heading.
