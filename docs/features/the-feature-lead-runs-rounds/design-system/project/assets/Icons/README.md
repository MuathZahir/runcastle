# Icons

The runcastle set, exported verbatim from `apps/web/src/icons.tsx`: 16×16 viewBox, 1.5px round stroke. The files are single-ink in `#8b8b94` (the dark theme's `icon`) because `<img>` cannot inherit colour; in the app use the `Icon` component, which draws with `currentColor`. Gaps to fill as the redesign lands: inbox, archive, sidebar-left, git-merge, external-link, copy.
