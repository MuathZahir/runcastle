# Logos

The castle mark — a crenellated wall whose gate is the run button — copied from `LogoMark` in `apps/web/src/icons.tsx`. Two single-ink files: `runcastle-mark-light.svg` (ink `#ededef`, for `canvas`/`surface` in dark) and `runcastle-mark-dark.svg` (ink `#18181b`, for light). Inline it with `fill: var(--text)` in the app. The mark is neutral now — it no longer wears the violet accent. Next to it, set "runcastle" in lowercase `ui-medium` sans; the two-tone mono wordmark is retired.
