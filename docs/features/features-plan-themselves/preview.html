Features plan themselves

Beside Start there is a second choice, "Plan it yourself". The feature then makes its own plan with nobody answering questions, and you come back to a preview and a Burn button. To change the plan, you open the chat and it is the grill you know.

What is left out

Later laps

  • Plans that start with nobody on the page, so a whole cut plans itself
  • What a feature waiting on a sibling does
  • Something that sends a run back to work, only if runs stop early
  • Making "Plan it yourself" the default
  • Self-planning a lap that is planned from review
  • "Plan the rest yourself" said in the middle of a grill
  • A time limit on a run

Not this feature

  • The preview's form and its place on the page (Plan preview owns them)
  • Burning, judging a lap, merging or starting drafts without you
  • The project session answering design questions
  • The charter change; the project session writes that record
  • Batched questions to you; your grill stays one at a time
