Before and after, for the human who comes back to a planned feature.

Today

  • The plan opens only if the agent opens it while you watch; the chat keeps nothing.
  • Designs hide behind "Open in design" buttons inside the plan page.
  • The Design tab vanishes when its server stops.
  • Your yes to round 1 commits designs you may never have opened.

With this feature

  • A Plan card and a card per design wait in the chat. 2 1
  • The Design tab is always there and lists every design. 6
  • A dot says something is new to you. 11
  • Approve on an opened design records your own yes; nothing else commits it. 8 9

interface DesignEntry {

  state: DesignState; isNew: boolean; shownAt: number
}
show_design({ path, title, width?, picture? })   // record + card (+ panel when attended)
show_plan()                                      // card (+ panel when attended)
set_design_state({ path, state })                // a yes or a no given in words
