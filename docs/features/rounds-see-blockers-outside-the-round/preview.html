Rounds see blockers outside the round

Under the hood
dispatchRound (features.ts)

Sweep orphaned burning rows → check every named ticket's blockers → refuse with the full list, or reset failed tickets and start the run.

startRun (runner.ts)

Scope stays the named tickets. It also hands the scheduler the seqs of finished blockers outside the scope.

readyState (ticket-burner.ts)

A blocker absent from the run but in that satisfied set counts as satisfied. Only a blocker absent from both still fails as "missing".
