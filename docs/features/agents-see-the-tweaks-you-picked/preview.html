Message the agent…

The line above the composer shows while a design is open; the sent message keeps it under your words. Neither can be edited or removed. Quiet text, the app's tertiary colour, with a small eye icon.

The agent gets your words, then:
[runcastle] Open in the Design tab: “Invoice list” (/preview/invoice-list), state “full”. Tweaks: accent = teal, density = compact.

Under the hood

 
// the page: window.parent.postMessage(report, '*')
{ type: 'runcastle:design',
  state: 'full' | null,                       // null: single-state page
  tweaks?: { accent: 'teal', density: 'compact' } }   // {} = no Tweaks menu; missing = did not say
  • corezod schema for the report; caps at 12 tweaks, 80 characters each.
  • webDesign view listens where event.source is its own frame (desktop and phone); a per-feature design-context store like the composer inbox; debounced design.report.
  • serverdesigns gains report, reportedAt, approvedReport; design.report mutation; approveDesign copies at the click; the approval line names values; feature context shows each report.
  • chatthread.send takes optional design; the agent gets text + one line; the human's bubble keeps their words and draws the line from display data.
