Facts

Waiting reason + its kind (new column, set by wait_for_you({ why, kind })), ready declarations, drives, human messages, open asks in any thread, merge conflicts, failed wakes, the holder.

featureNeed(facts)

Pure, in core. Precedence, words, the held rule, test vs merge. Returns one need or none.

Readers

need on the feature list and the feature → sidebar, status line, header, chat line, palette, tab count. Entering a need emits feature.needs_you → desktop and phone pings.
