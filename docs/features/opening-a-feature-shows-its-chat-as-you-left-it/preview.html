Opening a feature shows its chat as you left it

Open a feature whose chat ended and it resumes by itself. No Resume click, no message sent on its own. If you never type in it, it closes when you leave.

What happens to it after

Each live chat is a running Claude process, so one you never used doesn't linger. 2

Resumed on open→you leave: another feature, the project page, close the tab→ ~10 s with no view open →ended
Resumed on open→you reload, or click away and back within 10 s→stays
Resumed on open→it gets any prompt: you type, or runcastle wakes it→ordinary live chat, stays as today

Under the hood
page opens, chat at rest→launchSession({ kind: 'chat', auto: true })→resume only · no kickoff
can't resume→{ autoSkipped: reason }→nothing created, no toast
spawned→marked untouched (in memory)→last terminal view detaches → 10 s timer→endSession
any UserPromptSubmit→mark cleared

Same auto flag on the project chat's launch. Web: the chat column fires it once per visit to a conversation; the at-rest view gains a "Resuming…" state and swaps to the terminal once the session is live.
