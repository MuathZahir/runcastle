Under the hood
  • Static HTML, no JS, no build step. Each page loads styles.css, content.css and a new docs-only docs.css (the .doc-shot figure, up to 960px wide, and the stage row).
  • New site/_redirects (Cloudflare Pages, 301s); site/sitemap.xml lists the four docs URLs; the site README's file map is updated.
  • Captures: 2x PNGs of a 1440×900 window in site/assets/docs/, from a scratch data dir (a copy of the real database with only the demo project), the server booted from the checkout, live states staged after boot. Recipe and shot list go in the site README; no script.
  • Built by the lead in this checkout (workers cannot reach the real database). Then one review ticket: links, redirects, stale words, prose length, each picture against its caption.
