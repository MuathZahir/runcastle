Under the hood
Guards
The edit and install guards lift for the feature chat in every phase, not just from Go. No new worktree.
start_design_server
New MCP tool. Runs the agent's command in a runcastle-owned terminal in the talk worktree, with RUNCASTLE_DESIGN_PORT set. Finds the URL with the drive's URL sniffing. One per feature. Stops when the chat session ends, after 30 minutes with the pane closed, or when the feature ships.
show_panel
New MCP tool. Opens a panel view (design, tickets, preview, drive, details), with a path for design.
Go gate
Go is disabled while the talk worktree has uncommitted changes outside docs/features.
Select area
In the design pane the crop is saved as a PNG, and its path and your words are typed into the chat.
Layout
Overview and Chat tabs retire. Chat column, feature strip, one resizable panel, session switcher. The project page reuses the same pieces.
Skills
A design guide (preview pages, the two ways to reach a state, Tweaks, commit on approval). The plan preview's rules gain designed-screen entries. The tickets skill's text gains "connect, don't restyle".
