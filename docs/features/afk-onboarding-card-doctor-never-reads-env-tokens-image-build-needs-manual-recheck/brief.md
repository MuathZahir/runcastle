# AFK onboarding card: doctor never reads .env tokens, image build needs manual recheck

## Ticket 1

Bug: the AFK card's Claude Code token row stays amber ('no CLAUDE_CODE_OAUTH_TOKEN') even after Save & verify succeeds ('OAuth token captured to ~/.runcastle/.env'). Root cause: the tRPC doctor query (packages/server/src/trpc/routers/setup.ts:43) calls runDoctor without an `env`, so the afk-token probe reads bare process.env (packages/server/src/doctor/doctor.ts:604). The CLI doctor path already fixes this — packages/server/src/doctor/cli.ts:27-41 merges every runtime's afkKey from ~/.runcastle/.env over process.env — but the server tRPC path never got the merge, so a token saved to .env is permanently invisible to the web doctor. Fix: extract the CLI's .env-merge helper (or reuse it) and pass the merged env from the tRPC doctor route too, so a fresh read of ~/.runcastle/.env happens on every doctor query — not a boot-time snapshot, since Save & verify writes the file while the server is running. Regression test in packages/server/test: with CLAUDE_CODE_OAUTH_TOKEN present in the data-dir .env but absent from process.env, the tRPC doctor report marks the afk-token probe ok.

## Ticket 2

UX: building the sandcastle image from the AFK card requires manually clicking 'Done, recheck' — the card should detect completion itself. The build runs in a server-owned PTY (setup.startTerminal kind 'build-image', packages/server/src/trpc/routers/setup.ts:88-118) streamed to the embedded TerminalView; apps/web/src/components/EnableAfkCard.tsx wires recheck only to the manual onDone click (~line 165). The PTY registry knows when the process exits. Fix: surface build-terminal exit to the card — e.g. the PTY/WS transport already signals close, or emit a settings/setup event on PTY exit — and auto-trigger the doctor recheck when the build process ends (success or failure; the doctor probe itself decides whether the image is now present). Keep the manual button as fallback. While a build terminal is open, an inexpensive alternative/addition is polling the doctor image probe every few seconds; prefer the exit signal if it is reachable without new plumbing. Component test: when the build terminal reports exit, the card refetches the doctor report without a click.
